生成时间: 2026-09-26 11:59:19

一、五个方程(向量形式, 标量就是 1x1)
    预测:  x^- = F*x + B*u              P^- = F*P*F' + Q
    增益:  K   = P^-*H'*inv(H*P^-*H' + R)
    校正:  x   = x^- + K*(z - H*x^-)     P = (I - K*H)*P^-

    对应到你已经会的观测器:
    观测器:  xhat = F*xhat + L*(z - H*F*xhat)     L 靠自己选极点
    卡尔曼:  xhat = F*xhat + K*(z - H*F*xhat)     K 由噪声统计自动定
    形式完全相同。卡尔曼 = 增益按最小误差方差自动选取的观测器。

二、三个"为什么"
    1) 为什么是加权平均: 两个高斯相乘 -> 精度(1/方差)相加。
       本例: 先验 N(1.70,0.50^2) x 测量 N(2.10,0.20^2) -> 后验 N(2.0448,0.1857^2)
    2) 为什么 K 最优: 使 P+ = (1-K)^2*P- + K^2*R 最小 -> K = P-/(P-+R)。
       一个抛物线的顶点而已, 没有别的推导。
    3) 为什么与数据无关: K/P 的递推里没有随机量, 只看 F,Q,R,H,P0。
       所以能离线预算整条 K: 本例稳态 Kinf = 0.381244, P^-inf = 0.616147。
       稳态之后 K 是常数 -> 直接当常增益观测器用, 上机只剩矩阵乘法。

四、K 和 P 的物理含义(调参就看这两个数)
    K: 这一步拿新息(z - 预测)的百分之多少去修正估计。K 大 -> 跟得快但抖。
    P: 当前估计误差方差。它自己会收缩, 收缩到和 Q/R 平衡为止。
    P 突然变大 -> 模型跟不上实际, 该加大 Q。
    P 一直涨且不回落 -> 那个状态不可观测(见第六节)。

五、参数定错的症状
    Q 太小: 太信模型, 响应滞后, 曲线拖尾, 真机动跟不上。
    Q 太大: 太信测量, 曲线毛刺多, 滤波等于没做。
    R 太小 == Q 太大;  R 太大 == Q 太小。起作用的是 Q/R 之比, 不是绝对值。
    【最常见的实现坑】测量有 m 个通道时, R 必须是 m x m 矩阵, 不能给标量。
      3D 例子实测: R 用 3x3 矩阵 -> 位置 RMS 0.081, 速度 RMS 0.078;
                    R 误用标量   -> 位置 RMS 0.244, 速度 RMS 49.5 (完全跑飞)。
      原因: S = H*P*H' + R 的维数不对, 增益跟着错一个量级。
    判断手段: NIS 均值应约为 1(本例 0.862), NEES 均值应约为状态维数。
    偏离很明显就是 Q/R 定错了, 而不是"滤波器不好用"。

六、能不能估: 先看可观测性, 再看滤波
    判据: O = [H; H*F; H*F^2; ...; H*F^(n-1)], rank(O) == n 才可观测。
    1D 只测位置(2 状态): 秩 2/2 -> 可观测
    2D 匀速只测位置(2 状态): 秩 2/2 -> 可观测
    3D 匀速只测 x(6 状态): 秩 2/6 -> 不可观测
      现象: y z 估计误差 9.2 / 3.1 米, P22 从 1.04 涨到 2522
      原因: H*F^k 的 y z 两列恒为 0, 测量里根本没有 y z 的信息。
    3D 匀速测 xyz(6 状态): 秩 6/6 -> 可观测, 位置 RMS 0.0856, 速度 RMS 0.0761
    结论: 卡尔曼不会凭空造信息。不可观测的状态它只能给你一个发散的 P。

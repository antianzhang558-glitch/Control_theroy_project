## 1. 核心直觉：两个高斯相乘 = 按精度加权平均（脚本第 1 节，图 fig1）

一个不动的量，真值 2.00。你手里有两个信息：

- 先验估计（上一步的结果）：`x⁻ = 1.70`，标准差 `0.50`
- 本次测量（传感器读数）：`z = 2.10`，标准差 `0.20`

三种做法：

| 做法 | 结果 |
|---|---|
| A 直接平均：`(1.70+2.10)/2` | **1.9000** |
| B 按精度加权：权重取方差的倒数 | **2.0448**（权重 0.138 / 0.862） |
| C 卡尔曼一步：`x = x⁻ + K(z-x⁻)`，`K = P⁻/(P⁻+R)` | **2.0448**，K = 0.8621 |

**做法 C 完全等于做法 B（差 0.00e+00）**。也就是说：

```
卡尔曼滤波 = 按精度（方差的倒数）加权平均
1/P⁺ = 1/P⁻ + 1/R          ← 精度可以直接相加，这是全部的数学内核
```

- 合并后的方差 `P⁺ = 0.0345`，比先验 `0.25` 和测量 `0.04` **都小** → "信息只会越攒越多"。
- 谁的标准差小就更听谁：测量标准差 0.20 < 先验 0.50，所以结果明显偏向测量（权重 0.862）。

> 图 `fig1_两个高斯相乘.png` 把这三条曲线画在一起：黑线（后验）比蓝线（先验）和橙线（测量）都窄。

## 2. 增益 K 是什么、为什么最优（脚本第 2 节，图 fig2）

把校正公式展开：

```
xhat = x⁻ + K(z - x⁻) = (1-K)·x⁻ + K·z
```

**K 就是"测量在结果里的权重"**：

- `K = 0`：完全信模型，测量一眼不看
- `K = 1`：完全信测量，模型白算
- 实际总在 0 和 1 之间，按两边谁更靠谱分配

K 由两个不确定性之比决定：

| P⁻（模型） | R（测量） | K | 一句话 |
|---|---|---|---|
| 0.01 | 1.00 | 0.0099 | 基本信模型，测量只作微调 |
| 0.10 | 1.00 | 0.0909 | 基本信模型 |
| 1.00 | 1.00 | 0.5000 | 两边都听 |
| 1.00 | 0.10 | 0.9091 | 基本信测量 |
| 1.00 | 0.01 | 0.9901 | 基本信测量，模型只作平滑 |

### 为什么 K = P⁻/(P⁻+R) 就是最优的

"最优"只有一个含义：**让校正后的估计误差方差最小**。

```
P⁺(K) = (1-K)²·P⁻ + K²·R        ← 关于 K 的开口向上抛物线
dP⁺/dK = 0   =>   K = P⁻/(P⁻+R)   ← 顶点，推导到此结束
```

脚本用 20 万个点的数值扫描验证：数值最小点 0.50000，解析值 0.50000，差 0.00e+00。

> **这是卡尔曼滤波唯一需要"证明"的地方，而且它只是初中抛物线顶点。**

## 3. 五步递推与手算表（脚本第 3 节，图 fig3）

标量模型（`a=0.98, Q=0.25, R=1, P0=1`，`x(0)=0`，测量序列 `2.00 1.80 2.60 1.40 2.10 …`）：

```
预测（时间更新）： x⁻ = a·xhat_prev        P⁻ = a²·P_prev + Q
校正（量测更新）： K  = P⁻/(P⁻+R)
                   xhat = x⁻ + K·(z - x⁻)
                   P  = (1-K)·P⁻
```

实际跑出来的表（**建议拿计算器核一遍前两行**）：

| k | P⁻ | K | z(k) | 新息 z−x⁻ | xhat(k) | P(k) |
|---|---|---|---|---|---|---|
| 1 | 1.2104 | 0.5476 | 2.00 | +2.0000 | 1.0952 | 0.5476 |
| 2 | 0.7759 | 0.4369 | 1.80 | +0.7267 | 1.3908 | 0.4369 |
| 3 | 0.6696 | 0.4011 | 2.60 | +1.2370 | 1.8591 | 0.4011 |
| 4 | 0.6352 | 0.3884 | 1.40 | −0.4219 | 1.6580 | 0.3884 |
| 5 | 0.6231 | 0.3839 | 2.10 | +0.4751 | 1.8073 | 0.3839 |
| 6 | 0.6187 | 0.3822 | 1.70 | −0.0711 | 1.7439 | 0.3822 |
| 7 | 0.6171 | 0.3816 | 2.30 | +0.5909 | 1.9346 | 0.3816 |
| 8 | 0.6165 | 0.3814 | 1.55 | −0.3459 | 1.7640 | 0.3814 |
| 9 | 0.6162 | 0.3813 | 2.20 | +0.4713 | 1.9084 | 0.3813 |
| 10 | 0.6162 | 0.3813 | 1.45 | −0.4202 | 1.7100 | 0.3813 |

速算第一行：`P⁻ = 0.98²×1 + 0.25 = 1.2104`，`K = 1.2104/2.2104 = 0.5476`，`xhat = 0 + 0.5476×2.00 = 1.0952`，`P = (1−0.5476)×1.2104 = 0.5476`。

**K 从 0.5476 一路降到稳态 0.381244**：因为 P 每步变小，而 R 不变，所以越来越信模型。

稳态由不动点方程精确解出（这是"滤波器自己会收敛"的数学依据）：

```
p = a²·p·R/(p+R) + Q    →    p² + (R − a²R − Q)p − QR = 0
P⁻∞ = 0.616147,   K∞ = P⁻∞/(P⁻∞+R) = 0.381244
```

稳态还有一个好用的关系：**P = K·R**（校验：`(1−K∞)P⁻∞ = 0.38124448 = K∞·R`，差 0.00e+00）。

> **K 与数据无关**（第 4 节的重点）：K、P 的递推里没有任何随机量，只由 `(a, Q, R, P0)` 决定。
> 所以脚本能做机器精度级别的比对：150 步迭代的 K 与闭式稳态差 **5.55e-17**，P 差 **1.11e-16**。
> 工程含义：整条 K 序列可以**离线先算好**再上机，这就是"稳态卡尔曼滤波"，上机只剩几步矩阵乘法。

## 4. 从标量到向量：就是"标量写法换成矩阵"（脚本第 6 节，图 fig6）
| 标量 | 向量 |
|---|---|
| `x⁻ = a·x` | `x⁻ = F·x` |
| `P⁻ = a²·P + Q` | `P⁻ = F·P·Fᵀ + Q`（多了 Fᵀ，因为不确定性也跟着坐标变换转） |
| `K = P⁻/(P⁻+R)` | `K = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹`（除法变成求逆） |
| `xhat = x⁻ + K(z − x⁻)` | `xhat = x⁻ + K(z − H·x⁻)`（H 把状态映射到测量） |
| `P = (1−K)P⁻` | `P = (I − K·H)·P⁻` |

**没有新概念，只有新运算。** 第 3 节那张手算表的每一行都能逐项对上。

### 为什么要 `P·Fᵀ` 和 `H`：二维匀速模型实测

状态 `[位置; 速度]`，`F = [1 Ts; 0 1]`，**只测位置**（H = [1 0]），Ts = 0.1 s，位置测量噪声标准差 0.5 m：

| 做法 | 位置 RMS | 速度 RMS |
|---|---|---|
| 只用测量（不滤波） | 0.5016 | —— |
| 只用模型（匀速外推） | 50.78 | 4.91 |
| **卡尔曼滤波** | **0.2890** | **0.8273** |

- 位置精度比测量好 **1.7 倍**，比纯外推好 **175 倍**（纯外推没有速度修正，越走越偏）。
- **速度没有任何传感器直接测**，卡尔曼靠"位置–速度的耦合"估出来，RMS 0.83（真值范围 ±3 m/s）。
- 机制就是协方差矩阵的**互相关项 P₁₂**：位置测量里含速度的信息，滤波器通过 P₁₂ 从位置残差里反推速度。
- 一致性检验 NEES（= eᵀP⁻¹e，理论均值 = 状态维数 2）：实测 **1.656**，落在 3σ 带 [1.58, 2.42] 内 → Q、R 和真实噪声相符。

> 这一步的 K 是 2×1 向量，从 `[0.806; 0.310]` 收敛到 `[0.055; 0.016]`；**速度增益一开始比位置增益大**，因为速度更需要"纠"。

## 5. 能不能估，先看可观测性，不是看滤波器（脚本第 7 节，图 fig7）

这是最容易踩的坑：**卡尔曼滤波不会凭空造信息**。判据是你已经熟悉的那个：

```
O = [H; H·F; H·F²; …; H·F^(n-1)]     可观测 ⟺ rank(O) = n
```

三维匀速模型（状态 `[x y z vx vy vz]`，6 维）两种传感器方案：

| 方案 | H | rank(O) | 结果 |
|---|---|---|---|
| A 只测 x | `[1 0 0 0 0 0]` | **2 / 6 → 不可观测** | y、z 估计误差 9.20 m、3.14 m；P₂₂ 从 1.0 一路涨到 2522 |
| B 测 xyz | `[I₃ 0]` | **6 / 6 → 可观测** | 位置 RMS 0.0856，速度 RMS 0.0761（速度仍无传感器） |

为什么 A 不可观测：`H·F^k` 的 y、z 两列**恒等于 0**——测量值里根本不含 y、z 的信息，F 里也没有把 y 混进 x 的耦合。

于是：

- 估计值停在初值（0），误差就等于真值的位移；
- 协方差 P₂₂ 一直增长——**滤波器在诚实地告诉你"这个状态我不知道"**。

这不是"滤波器不好用"，任何估计器都救不回来。**工程结论：设计传感器方案时先算 rank(O)，再谈滤波。**

> 顺带一个实战坑（脚本和 `kalman_summary.txt` 里都记了）：多通道测量时 **R 必须是 m×m 矩阵，不能给标量**。
> 实测：3D 例子 R 用 3×3 → 位置 RMS 0.081、速度 RMS 0.078；R 误用标量 → 位置 0.244、**速度 49.5（完全跑飞）**。

## 6. 调参：K 太大太小都会变差（脚本第 8 节，图 fig8、fig9）

把卡尔曼换成"固定增益 K 的观测器"，K 就成了可以手调的旋钮（用一维那组数据）：

| 固定 K | 0.02 | 0.05 | 0.10 | **0.20** | 0.40 | 0.60 | 0.80 | 1.00 |
|---|---|---|---|---|---|---|---|---|
| 位置 RMS | 0.838 | 0.771 | 0.589 | **0.527** | 0.715 | 0.922 | 1.141 | 1.396 |

- 左边 K 小：太信模型 → 跟不上机动，曲线滞后；
- 右边 K 大：太信测量 → 噪声全进来，曲线毛刺；
- **卡尔曼做的事：利用 Q 和 R，每一步自动重新找这个谷底。**

### 参数定错的症状

| 症状 | 原因 |
|---|---|
| 曲线滞后、拖尾、跟不上真机动 | `Q` 定小了（太信模型） |
| 曲线毛刺多、滤波等于没做 | `Q` 定大了（太信测量） |
| 上面两种互换 | `R` 定小了 = `Q` 定大了；`R` 定大了 = `Q` 定小了 |

**起作用的是 Q/R 之比，不是单独哪个绝对值。**

### 怎么客观判断定错没定错：NIS / NEES 一致性检验

```
NIS  = 新息² / S        理论均值 = 1        （只看新息，可以在线做）
NEES = eᵀ·P⁻¹·e         理论均值 = 状态维数  （需要真值，只能离线评估）
```

实测：NIS 均值 **0.862**（3σ 带 [0.666, 1.334] 内），95% 分位点内比例 95.7%（理论 95%）；NEES 均值 1.656（理论 2）。

- NIS 明显 > 1 → R 定小了或 Q 定大了（滤波器过于自信）
- NIS 明显 < 1 → R 定大了或 Q 定小了（滤波器过于保守）

> 这个检验能通过，前提是**真值和滤波器假设的模型一致**。脚本里真值用"带限随机加速度"生成、滤波器的 Q 按同一个加速度算，所以 P 才有物理意义、置信带才可信（一维 3σ 覆盖率 100%）。

## 7. 和状态观测器 / LQR 的关系（连着已经会的东西）

先把观测器写出来：

```
观测器： xhat(k) = F·xhat(k-1) + L·(z(k) − H·F·xhat(k-1))
卡尔曼： xhat(k) = F·xhat(k-1) + K·(z(k) − H·F·xhat(k-1))
```

**形式完全相同。** 两者都是"模型预测 + 用新息按增益纠偏"，区别只在增益怎么来：

| | 观测器增益 L | 卡尔曼增益 K |
|---|---|---|
| 怎么定 | 人为选极点，反解 L | 由 Q、R、P 自动递推 |
| 是否时变 | 常数（线性时不变系统里） | 时变，并收敛到常数 |
| 依据 | 想要多快收敛 | 两个噪声方差 + 当前估计误差方差 |
| 最优性 | 无 | 使估计误差方差最小（线性无偏估计里最优） |
| 需要知道什么 | 对象模型 (F, H) | 对象模型 + Q + R + P0 |

四条结论：

1. **观测器是卡尔曼滤波的特例**。取 K 为常数，就是常增益观测器；稳态卡尔曼滤波 = 按噪声统计最优选增益的观测器。所以工程上常先离线算稳态 K，再当常增益观测器用。
2. **L 大 = 快但脏**。观测器把 L 加大误差收敛快，但每个测量噪声也被 L 放大进估计；卡尔曼的 K 自动把这个权衡做到最优——因为它知道 R 有多大。
3. **代价是必须知道 Q 和 R**。观测器不需要噪声统计；卡尔曼要求你把"模型有多不准、传感器有多不准"写下来。Q、R 定错，K 就不最优（这正是第 6 节的症状表）。
4. **和 LQR 的分工**：LQR 管"怎么控最好"（代价函数 J），卡尔曼管"怎么估最好"（误差方差）。两者拼起来就是 **LQG**，靠**分离原理**各自独立设计——这不巧，估和控的最优性可以分开做。

一句话总结：观测器教你"可以用测量纠偏"，卡尔曼回答"**纠多少最优**"，而 K 就是这个答案。

## 8. Simulink 模型与严格对照（`compare_simulink_kf`）

| 模型 | 内容 | 建模方式 |
|---|---|---|
| `kalman_simple.slx` | 一维标量，与第 3 节同一套参数 | Sum / Product / Divide 把五个方程一个个摆出来，适合逐模块对公式 |
| `kalman_cv.slx` | 二维匀速模型，只测位置 | 滤波器用 **MATLAB Function 块**（代码就是矩阵形式的五个方程）；真值用标量方程搭 |

**对照思路（本例最漂亮的地方）**：K 和 P 的递推里不含随机量，所以只要两边参数一样，**K 序列必须逐点相等**；再把模型输出的同一组 `z` 喂给 MATLAB 版递推，连状态估计序列也必须完全一致。

`validation_simulink.txt` 的实测结果：

| 项 | 最大差 |
|---|---|
| 一维 K 序列 | 1.1e-16 |
| 一维 P 序列 | 2.2e-16 |
| 一维估计序列 | 8.9e-16 |
| 二维 K / P / 估计序列 | **0.00e+00** |
| 一维末步 K vs 解析稳态 | 0.00e+00 |

> 为什么二维能做到"差 0"：Simulink 的 MATLAB Function 块和 MATLAB 脚本用同样的运算顺序，全部是 double 加法/乘法，没有别的噪声源。

### 用 Simulink 搭线性系统时的两个踩坑记录（脚本注释里也写了）

1. **常数矩阵 `[1 0]` 在 Simulink 里是"一维"信号，而矩阵乘法模块要求二维**，`(1×2)×(2×2)` 会直接报维度错。一维模型的 Sum 用 `|` 形式（端口同侧竖排）能避免连线打结。
2. 多个模块共用同一个常量时，直接在模块里填数值更省事（例如 `F` 同时给 `F·x` 和转置用），但要注意**维度来源必须明确**，否则报错信息指向的是下游模块，找起来很费时间。

## 11. 建议练习（改一个数，重跑，看哪个结论变了）

1. 第 3 节把 `R` 改成 0.25 → K 变大、更信测量；改成 4 → K 变小、更信模型。
2. 第 5 节把 `sb5` 由 2.0 改成 0.5（真值更平滑但 Q 不变）→ 滤波器变保守、滞后，置信带偏大。
3. 第 5 节把 `sb5` 和 `Q5` 一起改成 0.5 → 置信带重新变准（3σ 覆盖率回到 ~99.7%）。
4. 第 7 节把 `HA` 换成 `[1 1 0 0 0 0]`（测 x+y）→ rank 仍然是 4，z 依然不可观测。
5. 把第 6 节 `P06` 的速度初值从 4 改成 100 → 头几步速度增益很大，收敛更快也更抖。
6. 打开 `kalman_cv.slx`，双击 `kfstep` 块，把里面的矩阵方程和 `run_all_kalman` 第 6 节逐行对一遍。

# 全维状态观测器入门

这是一个二阶弹簧—质量—阻尼系统，只测位置，估计位置和速度，并用估计状态进行反馈控制。

## 运行

在 MATLAB 中进入本目录，执行 `run_observer_demo`。首次运行生成 `full_order_observer_intro.slx`，并生成响应图、数据与验证记录。之后可直接打开 slx 点击运行，参数已保存在模块内，不依赖工作区初始化。Scope 的四条曲线依次为真实位置、真实速度、估计位置、估计速度。运行脚本可看到分开的四幅图。

需要 MATLAB 和 Simulink，不需要 Control System Toolbox。脚本不会覆盖已经存在的模型；验证针对下述默认参数，修改模型后如验证失败，应检查是否是参数与默认设计不同。

## 1. 被控对象

质量 m=1 kg，阻尼 b=3 N·s/m，弹簧刚度 k=2 N/m：

    位置二阶导数 + 3×位置一阶导数 + 2×位置 = u
    x1 = 位置，x2 = 速度，y = x1
    A = [0 1; -2 -3], B = [0;1], C = [1 0]
    x_dot = A*x + B*u

真实初值 x(0)=[0.5;0]，估计初值 xhat(0)=[0;0]。刻意让初值不同，才能看清观测器纠正误差的过程。

## 2. 为什么能观测

可观测矩阵 [C; C*A] = [1 0;0 1]，秩为 2，所以两个状态都能重建。全维指观测器也有两个状态，即使位置已测得，仍然估计位置和速度。

## 3. 手算观测器增益 L

    xhat_dot = A*xhat + B*u + L*(y-C*xhat)
    L = [l1;l2]

预测部分 A*xhat+B*u 模拟对象；校正部分 L*(y-C*xhat) 利用测量位置与估计位置的差来纠偏。

令 e=x-xhat，两式相减得 e_dot=(A-L*C)*e。注意真实对象和观测器使用同一个 u。

    det(sI-(A-LC)) = s^2 + (3+l1)*s + 3*l1+2+l2

选择观测器极点 -5、-6，目标多项式 (s+5)(s+6)=s^2+11s+30。比较系数：l1=8，l2=4，因此 L=[8;4]。

展开后更容易对照模型：

    估计位置导数 = 估计速度 + 8*(测量位置-估计位置)
    估计速度导数 = -2*估计位置-3*估计速度+u+4*(测量位置-估计位置)

## 4. 用估计状态控制

采用 u=-K*xhat+N*r，目标 r=1 m。可控矩阵 [B A*B]=[0 1;1 -3]，秩为 2。

    det(sI-(A-BK)) = s^2+(3+k2)*s+2+k1

选择控制极点 -2、-3，比较 (s+2)(s+3)=s^2+5s+6，得 K=[4 2]。

稳态 x=[r;0]，弹簧需要 u=2r；代入控制律 u=-4r+Nr 得 N=6。该前馈保证准确模型下常值目标的稳态跟踪，没有积分器，所以不保证存在未知恒定扰动或模型误差时仍然无静差。

在 [x;e] 坐标中闭环矩阵为 [A-BK, BK; 0, A-LC]，所以闭环极点是 -2、-3、-5、-6。这就是分离原理在本例中的体现。

## 5. 看模型时的顺序

1. Reference → N → ControlSum → Plant：输入和真实对象。
2. PositionSensor：仅把真实位置送给观测器，真实速度只用于画图对照。
3. Innovation：计算 y-C*xhat。
4. A、B、L → ObserverSum → EstimatedState：组成观测器微分方程。
5. K → ControlSum：估计状态反馈。

位置和速度估计应逐渐与真实值重合，误差趋于零，位置趋于 1 m、速度趋于零，输入趋于 2 N。某个误差分量可以先增大后减小；稳定并不意味着每个分量单调衰减。

## 6. 建议练习

先把观测器初值改成真实初值，观察误差是否一直为零。然后将观测器极点改为 -2、-3，手算得到 L=[2;-2]，观察估计收敛变慢。最后尝试 -10、-12，对应 L=[19;61]。更快的观测器通常会对测量噪声更敏感；当前例子是无噪声、准确模型，不能单凭此例认为极点越快越好。

脚本的自动验证比较 Simulink 与增广系统矩阵指数精确解，同时检查 e(t)=exp((A-LC)t)e(0) 和最终跟踪结果。修改参数进行练习时，需要同步调整脚本参数、极点断言和模型中的对应模块。

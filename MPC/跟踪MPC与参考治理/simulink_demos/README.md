# 人工参考MPC与RG＋PI：两个最小Simulink教学模型

## 打开与运行

1. 双击 `MPC_RG_Teaching.prj`，项目启动时打开两个模型；也可在 MATLAB 中打开本文件夹运行 `open_demos`，或直接双击两个 `.slx` 文件。
2. 点击模型的 Run 按钮（普通 Normal 仿真模式）。
3. 双击 `Tracking_scope`：三条线依次是用户目标、人工参考/RG参考、实际输出。
4. 双击 `Input_scope` 看实际控制输入。RG模型另有 `Kappa_scope` 看推进比例。
5. 运行 `run_demos` 可一次运行两个模型，并生成 `comparison.png` 和可编辑的 `comparison.fig`。

需要 MATLAB、Simulink；人工参考MPC另需 Optimization Toolbox（quadprog）。本机按 R2025b 构建。MATLAB Function 块通过 `coder.extrinsic` 调用同目录函数，供普通仿真使用，不是部署/代码生成版本。请保留本目录完整，不要只复制一个SLX。

## 看哪两个模型

| 文件 | 观察重点 |
|---|---|
| `mpct_simple.slx` | 联合选择人工稳态与未来输入，只执行第一个输入 |
| `rg_pi_simple.slx` | RG计算参考和κ；PI根据参考计算输入；参考不变时对象仍会变化 |

共同对象为无量纲教学系统：`x(k+1)=0.9*x(k)+0.1*u(k), y=x`，采样周期为1。状态与输入范围均为 `[0,1]`；人工稳态或RG参考范围为 `[0,0.98]`。稳态满足 `u=x`。这是为了看清算法分工选取的假设对象，不是斯特林模型，也不是原论文复现。

用户目标在10秒变为0.7，80秒变为1.2，160秒降为0.3。中间的1.2超过允许稳态范围，用来观察方法怎样处理不可达要求。默认运行到240秒。参考信号保存在各模型的 Model Workspace 中，名为 `reference_data`；`From Workspace` 块读取它。

## 模型内部

双击 `Plant` 可见输入增益0.1、状态记忆0.9和单位延迟。双击RG模型中的 `PI` 可见比例与积分分支：`u=2*(v-x)+I`，`I(k+1)=I(k)+0.2*(v-x)`。

### 人工参考MPC

`simple_mpct_step.m` 中的决策变量是未来10个输入和一个人工稳态 `s`。由于本对象的稳态输入恰好等于稳态状态，`xa=ua=ya=s`，已精确消去多余变量，不是忽略稳态输入。

代价由预测状态相对`s`的偏差、预测输入相对`s`的偏差，以及`s`相对用户目标的偏差组成，权重分别为 `Q=1, R=0.1, S=20`。逐步检查状态/输入约束，并采用终端等式 `x_N=s`。因此无需另算终端集合或另加终端代价，末端可用恒定输入`s`保持。

### RG＋PI

`simple_rg_step.m` 根据对象状态、PI积分状态、上次参考及本次用户目标，计算满足约束的最大κ，再更新 `v=previous_v+kappa*(r-previous_v)`。PI仍单独产生实际输入，不用输入饱和掩盖RG失败。

预测模型是PI与对象合并后的闭环。除了检查前40步，还通过特征值0.9/0.8的衰减界约束无限预测尾部；不是任意截断40步就声称永远合规。尾部界与线性约束组合是保守的允许集合，名义初始状态为零。初态、对象或PI参数变化后需重新检查/修改配套算法，不能只改框图参数就沿用旧RG保证。

## 可以怎么学

先观察10秒时人工参考/RG参考怎样变化；再观察80秒时用户要求1.2而实际输出停在哪里；最后观察160秒降低目标时输入怎样调整。两者参数不代表公平性能整定，不依据一张曲线宣布哪个算法更好。

本文件仅是操作说明。模型、代码和仿真交付不等于用户已掌握方法，不替代用户自己的主要笔记。

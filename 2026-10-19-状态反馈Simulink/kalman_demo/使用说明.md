# 简单卡尔曼滤波仿真

**二维基础模块版：`kalman_beginner_2d.slx`，配套 `二维入门_搭建与性能评价.md`。** 状态为温度与温度变化速度，只有温度测量，滤波过程分为预测、算增益、测量校正三个基础模块子系统。

**初学者请先打开 `kalman_beginner_temperature.slx`，并阅读 `先看这个_初学者搭建说明.md`。** 新入门版用一维温度和基础模块逐步展示预测、增益、校正。下面保留原二阶位置/速度模型的说明，供进一步学习。

打开 kalman_position_velocity.slx 后直接运行，不需要预先初始化工作区，也不依赖专门的卡尔曼滤波工具箱模块。需要 MATLAB、Simulink；滤波算法嵌入 MATLAB Function 模块。

这是状态估计项目：真实物体沿直线运动，传感器只能测到有噪声的位置，卡尔曼滤波器根据位置测量同时估计位置和速度。滤波器并不控制物体运动。

## 对象和噪声

状态 x=[位置;速度]，采样周期 Ts=0.1 s，仿真 20 s。

    x(k+1) = A*x(k) + G*a(k)
    z(k)   = H*x(k) + v(k)
    A = [1 0.1; 0 1]
    G = [0.005; 0.1]
    H = [1 0]

独立零均值高斯噪声：随机加速度 a 的方差为 0.04，位置测量噪声 v 的方差 R=0.25（标准差 0.5 m）。过程协方差 Q=G*0.04*G'。真实初始状态为 [0;1]，滤波初始先验为 [0;0]，P=eye(2)。随机种子固定，便于重复比较。

## 查看模型

- Position - true measured estimated：三个输入依次是真实位置、测量位置、滤波位置。
- Velocity - true estimated：两个输入依次是真实速度、估计速度。
- Kalman gain：位置和速度对应的两个卡尔曼增益。
- 双击 Kalman Filter，再双击 Correct and predict，查看预测与校正公式。Unit Delay 保存下一采样时刻的先验状态和协方差，避免代数环。

每个采样点先用当前位置测量校正先验，再预测下一采样点：

    K = Pprior*H'/(H*Pprior*H'+R)
    xhat = xprior + K*(z-H*xprior)
    Ppost = (I-K*H)*Pprior*(I-K*H)' + K*R*K'
    xprior_next = A*xhat
    Pprior_next = A*Ppost*A' + Q

其中协方差校正采用 Joseph 形式。滤波器输入只有带噪声的测量位置，没有真实状态。

## 文件与调整

- build_kalman_demo.m：重新生成模型、仿真、独立递推核对并生成响应图。
- kf_step.m：嵌入模型的算法源文件；修改此文件后运行生成脚本，使修改更新到模型。
- kalman_response.png：仿真曲线。
- kalman_results.mat：真实值、测量、估计、增益和误差指标。
- matlab_build.log：构建与验证结果。

增加传感器噪声时，同时修改 Sensor noise 的 Variance 和滤波算法中的 R；修改随机加速度方差时，同时修改 Acceleration noise 的 Variance 和算法中的 Q。只修改滤波器的 Q/R，则是在实验模型失配。

误差统计使用 t>=2 s 的数据，以单独观察初始速度估计收敛后的表现。单次随机仿真的改善不代表所有噪声实现下逐点误差都更小。

# 从一维温度走到二维状态

打开 **kalman_beginner_2d.slx**，直接点击运行。所有参数保存在模型工作区，无需先运行初始化脚本。原一维模型保留，可以对照学习。

这里“二维”指两个状态，不是两个空间方向：

    x = [温度T; 温度变化速度r]

传感器仍只有一个，只测温度。我们希望从连续的温度测量中，同时估计温度和它变化的速度。

## 1. 为什么需要第二个状态

一维模型预测时直接沿用上一拍温度。现在假设我们还知道温度每秒升高多少，就能预测得更合理：

    下一拍温度 = 当前温度 + 0.1 × 当前变化速度 + 温度过程噪声
    下一拍变化速度 = 当前变化速度 + 速度过程噪声

矩阵形式为：

    x(k+1) = A*x(k) + w(k)
    z(k) = H*x(k) + v(k)
    A = [1 0.1; 0 1]
    H = [1 0]
    Q = diag([0.001 0.0001])
    R = 0.25

采样周期0.1 s，真实初始状态[20;0.1]。温度、变化速度的过程噪声独立；测量噪声标准差为sqrt(R)=0.5。各噪声独立且种子固定。

只有温度测量也能估计速度，是因为多个时刻的温度提供了变化趋势。本系统的可观测矩阵[H;H*A]=[1 0;1 0.1]满秩。这个性质叫可观测性，与前面讨论的可控性不同。

## 2. 顶层按三步读

Unit Delay保存上一次的估计和P，随后进入下面三个子系统。双击子系统，里面全部是基础模块，没有MATLAB Function。

| 顺序 | 子系统 | 做什么 |
|---|---|---|
| 1 | 预测 | 根据上一拍的温度和变化速度，预测本次状态和不确定度 |
| 2 | 计算增益K | 算出本次测量分别能修正温度、变化速度多少 |
| 3 | 测量校正 | 用当前测量与预测测量的偏差修正两个状态，并更新P |

右边To Workspace只记录数据，不属于算法。

## 3. 对照一维公式

| 内容 | 一维温度模型 | 本二维模型 |
|---|---|---|
| 状态x | 一个数 | 2×1：[温度;变化速度] |
| 误差协方差P | 一个数 | 2×2矩阵 |
| 测量z | 一个数 | 仍然是一个数 |
| 卡尔曼增益K | 一个数 | 2×1：[温度增益;速度增益] |
| 预测状态 | x_minus=x_prev | x_minus=A*x_prev |
| 预测不确定度 | P_minus=P_prev+Q | P_minus=A*P_prev*A'+Q |
| 增益 | K=P_minus/(P_minus+R) | K=P_minus*H'/(H*P_minus*H'+R) |
| 校正状态 | x_hat=x_minus+K*(z-x_minus) | x_hat=x_minus+K*(z-H*x_minus) |
| 校正不确定度 | P=(1-K)*P_minus | P=(I-K*H)*P_minus |

I是2×2单位矩阵。P的对角线分别是温度估计误差方差、速度估计误差方差；非对角项表示两种估计误差之间的相关性。不能只把一维P复制两份而忽略它们的联系。

例如预测温度20、本次测量21、K=[0.2;0.05]，则温度修正+0.2，变化速度修正+0.05。两个状态共享同一个测量偏差，但各有各的增益。二维情况下不能把两个增益都简单理解成0到1之间的加权比例。

## 4. 每个子系统怎么手工搭

### 1 预测

- “上拍估计”接Gain，Gain=A，Multiplication选择Matrix(K*u)，输出预测状态。
- “上拍P”先接Gain=A，选择Matrix(K*u)，得到A*P；再接Gain=A'，选择Matrix(u*K)，得到A*P*A'。
- 上述结果与Constant=Q通过Sum相加，得到预测P。

这里Gain参数中的K是Simulink对“增益参数”的通用记号，并非一定指卡尔曼增益。

### 2 计算增益K

- 预测P接Gain=H'，使用Matrix(u*K)，得到2×1的P_minus*H'。
- 这个结果分两路：一路作为Divide的分子；另一路经过Gain=H，使用Matrix(K*u)，再加Constant=R，得到标量分母S。
- Divide用逐元素除法即可，因为分母只有一个数，结果为2×1的K。无需求逆模块。

### 3 测量校正

- 预测状态接Gain=H，得到预测温度。
- Sum计算“测量温度−预测温度”，得到一个标量偏差。
- Product计算K×偏差；另一个Sum把这个2×1修正量加到预测状态上，得到估计状态。
- 另一条支路：K接Gain=H，使用Matrix(u*K)，得到K*H；从Constant=eye(2)中减去它，再用Product右乘预测P，得到校正后的P。
- 两个Product都设置Multiplication=Matrix(*)。矩阵乘法的顺序不能交换，也不能随意使用逐元素乘法。

估计状态与校正P分别反馈到两个Unit Delay。初值分别为[18;0]与diag([4 1])，采样时间均为0.1。第一拍也先经过预测，与一维入门版使用同样的时序约定。

## 5. 怎么评价二维性能

分别计算两个状态的误差，不把不同单位混在一个RMSE里：

    温度误差 = 估计温度 - 真实温度
    变化速度误差 = 估计变化速度 - 真实变化速度
    RMSE = sqrt(mean(误差.^2))

- 温度RMSE：与原始温度测量RMSE比较，判断滤波是否改善准确度。
- 变化速度RMSE：与仿真中已知的真实变化速度比较。由于传感器没有直接测量速度，没有“原始速度测量RMSE”。
- 初始收敛：观察估计从[18;0]向真实状态附近靠近的过程。
- 跟随能力：温度变化速度发生变化时，估计是否出现明显延迟或长时间偏差。

脚本统计t>=2 s的RMSE；2 s只是剔除初始过程的统计窗口，不是对所有运行都保证的收敛时间。换多个随机种子重复仿真，可以进一步评价平均性能。

温度Scope三个输入依次为真实温度、测量温度、估计温度。速度Scope两个输入依次为真实变化速度、估计变化速度。增益Scope显示两个分量。

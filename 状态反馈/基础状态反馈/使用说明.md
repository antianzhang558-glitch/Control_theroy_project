# 简单状态反馈 Simulink 模型

打开 `simple_state_feedback.slx`，点击运行，双击 `States x1 and x2` 查看两个状态，双击 `Control u` 查看控制输入。仿真时间为 8 秒。

系统为：

\[
\dot x=Ax+Bu,\quad A=\begin{bmatrix}0&1\\0&0\end{bmatrix},\quad B=\begin{bmatrix}0\\1\end{bmatrix}.
\]

反馈律为 \(u=-Kx\)，其中 \(K=[2\quad3]\)。初始状态为 \(x(0)=[1\quad0]^T\)。闭环矩阵 \(A-BK\) 的特征值为 -1、-2，因此状态收敛到零。

你提出的 `y=-kx` 在这里作为控制输入，按控制系统常用记号写成 `u=-Kx`。State-Space 模块设置 `C=eye(2)`、`D=zeros(2,1)`，输出完整状态向量 x，送入增益为 `-K` 的 Gain 模块后返回系统输入。Gain 使用矩阵乘法。

模型参数保存在模型工作区中，直接打开 slx 即可运行，不需要先执行脚本。打开模型后可通过 Model Explorer 中的 Model Workspace 修改 A、B、C、D、K 和 x0。

运行 `build_state_feedback.m` 可重新生成模型、执行仿真并验证结果。`state_feedback_response.png` 是响应曲线，`simulation_results.mat` 保存仿真数据。

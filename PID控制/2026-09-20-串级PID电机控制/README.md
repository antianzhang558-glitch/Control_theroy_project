# 串级 PID 直流电机位置控制

这是一个中等难度的 Simulink 学习模型：位置 PID 外环产生转速指令，转速 PI 内环产生电枢电压。可以练习双闭环反馈、物理建模、控制器整定、限幅和抗负载扰动。内环 PI 是 PID 的 D=0 特例。

## 直接使用

用 MATLAB 打开 `cascade_pid_motor.slx`，点击运行即可。参数保存在模型工作区，无需先运行初始化脚本。需要 MATLAB 和 Simulink；不需要 Simscape 或自动整定工具箱。

也可以将 MATLAB 当前文件夹切换到本目录，然后运行：

```matlab
run_cascade_pid          % 打开模型、仿真、画图并导出结果
validate_cascade_pid     % 四组场景检查
```

`build_cascade_pid` 用来从源代码重建模型。为避免覆盖手工调整，它发现同名模型文件或已打开模型时会停止。需要重建时请先另存并关闭自己的模型。

## 结构与难度

位置指令 → 位置误差 → 位置 PID → 转速指令 → 转速误差 → 转速 PI → 电压 → 直流电机 → 转速 → 积分 → 位置。

实际转速反馈到内环求和点，实际位置反馈到外环求和点。负载转矩在电机机械方程中减去，而不是直接加在位置输出上。双击 `DC motor` 可以看到电气与机械环节以及反电动势反馈。

电机方程：

```text
L di/dt = u - R i - Ke·ω
J dω/dt = Kt·i - b·ω - TL
dθ/dt = ω
```

这是教学用的集总参数模型，未建模齿轮间隙、库仑摩擦、PWM、采样延迟和电流保护；电压限制不等于电流限制。

## 默认参数

| 参数 | 数值 | 含义 |
|---|---:|---|
| R | 1 Ω | 电枢电阻 |
| L | 0.01 H | 电枢电感 |
| Kt | 0.1 N·m/A | 转矩常数 |
| Ke | 0.1 V·s/rad | 反电动势常数 |
| J | 0.01 kg·m² | 转动惯量 |
| b | 0.001 N·m·s/rad | 黏性阻尼 |
| 位置 PID：P / I / D | 4 / 3 / 0.05 | 并联形式，输入 rad，输出 rad/s |
| 位置微分滤波 N | 30 s⁻¹ | 微分项为 D·N·s/(s+N) |
| 转速 PI：P / I | 4 / 40 | 并联形式，输入 rad/s，输出 V |
| 转速指令限制 | ±8 rad/s | 外环输出限幅，不是实际转速硬限幅 |
| 电压限制 | ±24 V | 内环输出限幅 |
| 抗积分饱和 Kb | 外环 1，内环 20 | back-calculation |

两级控制器都使用模块内置输出限幅和反算抗积分饱和。机制参考 [MathWorks PID 抗积分饱和说明](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。

## 默认实验（16 秒）

| 时间 | 事件 | 观察内容 |
|---|---|---|
| 0.5 s | 位置由 0 跳到 +90° | 跟踪速度、超调、启动电压 |
| 4 s | 加入 0.05 N·m 负载 | 短暂位置偏差与恢复、电流增大 |
| 8 s | 位置由 +90° 跳到 −90° | 反向运动和限幅恢复 |
| 12 s | 撤掉负载 | 扰动恢复 |

`Position scope` 显示 [给定位置, 实际位置]，单位 rad；`Speed scope` 显示 [给定转速, 实际转速]，单位 rad/s；`Actuator scope` 显示 [电压 V, 电流 A, 负载 N·m]，三条曲线量纲不同。配套脚本将位置转换成度，并分图展示执行器信号。

## 推荐练习顺序

1. 先运行默认参数，理解两条反馈线与负载注入点。
2. 在转速 PI 模块中减小或增大 P、I，比较位置响应和转速响应的变化。整定原则是先内环、后外环；内环应比外环快。
3. 保持内环不变，调整位置 PID。增大 P 通常加快位置跟踪，但过大可能振荡；I 消除残余偏差，但过大易超调；D 配合滤波改善阻尼。
4. 通过“建模 → 模型资源管理器 → 模型工作区”将 J 改为 0.015，或将 load_torque 改为 0.1，观察鲁棒性。
5. 将 theta_step 改为 4*pi、theta_change 改为 -8*pi，观察限幅。再对比 PID 模块关闭抗积分饱和后的恢复时间。

模块参数可以直接改为数值，也可以保留变量名并修改模型工作区。仿真后按 Ctrl+S 保存自己的调整。当前微分作用于位置误差，因此阶跃指令可能引发短暂微分冲击，模型使用滤波和限幅约束输出；可进一步练习给定预滤波或微分先行。

## 文件与验证

- `cascade_pid_motor.slx`：可独立打开运行的模型。
- `model_overview.png`：模型总览。
- `response.png`：运行入口生成的响应图。
- `simulation_results.mat`：三组记录信号与仿真结果。
- `validation.txt`：四组场景实测结果与 MATLAB 版本。
- 三个 `.m` 文件：构建、运行、验证入口。

验证覆盖默认参数、惯量增加 50%、负载加倍和大幅位置指令；检查数值有限、控制器输出限幅、最终误差和末段收敛。它是指定场景的数值验证，不是所有参数范围内的稳定性证明。运行及验证脚本会更新本目录的相应结果文件，不会覆盖已保存的模型参数。

本机 R2025b 实测四组检查均通过。默认首次阶跃超调约 11.12%，16 秒位置误差约 0.035°；大幅指令场景末端误差约 0.316°。默认峰值电流约 21.11 A（模型未设置电流保护）。诊断过程记录保存在 diagnostics 子目录。

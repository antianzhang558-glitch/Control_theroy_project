# 最简单的水箱串级控制

打开 simple_cascade_tank.slx，点击“运行”，再双击“看水位变化”。

你只需要先看懂三句话：

1. 水位不够，外环 PI 就要求增加进水流量。
2. 流量不够，内环 PI 就加大水泵指令。
3. 水进入水箱，水位逐渐接近目标。

模型从左往右依次为：目标水位 → 水位误差 → 外环 PI → 流量误差 → 内环 PI → 水泵 → 水箱 → 水位曲线。

下面两条回线分别反馈实际流量和实际水位。外环输出的是“目标流量”，内环输出的是“水泵指令”。PI 就是 D=0 的 PID。

水泵用 1/(0.2s+1) 表示，意思是水泵不会瞬间达到所需流量。水箱用 1/(5s+1) 表示，意思是水位变化更慢，同时水箱有随水位增大的自然排水；保持水位时仍需要进水。所有量采用归一化数值，这是便于理解的线性教学模型。

外环 P=2、I=0.4；内环 P=2、I=10。参数直接写在模块里，无需初始化。先不要调参数，先看目标流量如何连接两个反馈环。

文件：simple_cascade_tank.slx 是模型，build_simple_tank.m 是构建脚本，simple_tank_response.png 是响应图，simple_tank_validation.txt 是实际验证记录。已存在模型时构建脚本会停止，避免覆盖你的改动。

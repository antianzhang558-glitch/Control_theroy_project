# PID 练习

本目录保留三个原有 PID 模型，便于分别查看和继续实验。

| 文件 | 说明 |
|---|---|
| [PID.slx](PID.slx) | PID 练习模型 |
| [PID_classic.slx](PID_classic.slx) | classic 命名的 PID 模型 |
| [PID_temp.slx](PID_temp.slx) | temp 命名的已有模型，保留供继续练习 |

在 MATLAB 中切换到本目录，打开所需模型，检查对象、PID 参数、仿真时间及 Scope，再运行仿真。若提示缺少工作区变量，需按模型中参数表达式补齐初始化数据。

本次仅归档，未核实三个模型的全部差异或重新仿真；文件名不代表验证状态。
